話した日本語を、カーソルのある場所に入力するアプリです。音声の認識はすべて PC の中で行い、インターネットには接続しません。

Powered by Moonshine AI

## ダウンロード

| OS | ファイル |
| --- | --- |
| Windows 10 / 11 | `moonshine-dictate-0.2.0-windows-setup.exe` |
| macOS（Apple Silicon の Mac のみ） | `moonshine-dictate-0.2.0-macos-arm64.dmg` |
| Linux（x86_64） | `moonshine-dictate-0.2.0-linux-x86_64.AppImage` |

インストールの手順と使い方は `使い方.md` にあります。

## 0.2.0 で変わったこと

- 音声認識のモデルを `base`（日本語）に変えました。0.1.0 の `small-streaming` より認識の精度が高くなります。区切りが確定してから文字が出ます
- 設定画面を追加しました。アイコンのメニューの「設定…」から、ホットキー、マイク、句読点の入れ方、置換表などを変えられます
- 句読点の入れ方を選べるようにしました（認識結果のまま／区切りの終わりに「。」を足す／入れない）
- 「そ の 中 で」のように、日本語の文字の間に入る余分な空白を取り除くようにしました
- 初めて起動したときに、使い方の画面を出すようにしました。アイコンのメニューの「使い方」からいつでも開けます
- Windows でライブ入力の文字の順番が入れ替わる不具合を直しました

## 注意

- **Windows：** 電子署名がないため、初回の実行時に「Windows によって PC が保護されました」と表示されます。「詳細情報」から「実行」を押してください。スマート アプリ コントロールがオンの PC では、実行が止められることがあります。
- **macOS：** Apple の署名と公証を受けていません。初回は右クリックして「開く」を選んでください。Intel の Mac には対応していません。
- 0.1.0 から更新した場合、設定ファイルに `small-streaming` が残っていると、自動で `base` に切り替えて通知します。
