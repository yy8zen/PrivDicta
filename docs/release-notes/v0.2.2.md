話した日本語を、カーソルのある場所に入力するアプリです。音声の認識はすべて PC の中で行い、インターネットには接続しません。

Powered by Moonshine AI

## ダウンロード

| OS | ファイル |
| --- | --- |
| Windows 10 / 11 | `privdicta-0.2.2-windows-setup.exe` |
| macOS（Apple Silicon の Mac のみ） | `privdicta-0.2.2-macos-arm64.dmg` |
| Linux（x86_64） | `privdicta-0.2.2-linux-x86_64.AppImage` |

インストールの手順と使い方は `privdicta-user-guide-ja.md` にあります。

## 0.2.2 で変わったこと

- 認識の結果が、文の途中で切れることが多かったのを直しました。認識エンジンの「1秒の音声あたりに出す文字数の上限」が英語向けの値のままだったためです。日本語向けに公式が勧める値（13.0）にしました。7つの例文で測ったところ、文字の誤り率が 18.6% から 4.9% に下がり、録音を終えてから入力されるまでの時間は最大 0.45 秒でした
- 開発者向けに、認識の誤り率と待ち時間を測るスクリプト（`scripts/benchmark_accuracy.py`）を追加しました

## 注意

- **Windows：** 電子署名がないため、初回の実行時に「Windows によって PC が保護されました」と表示されます。「詳細情報」から「実行」を押してください。スマート アプリ コントロールがオンの PC では、実行が止められることがあります。
- **macOS：** Apple の署名と公証を受けていません。初回は右クリックして「開く」を選んでください。Intel の Mac には対応していません。
