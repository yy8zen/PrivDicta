話した日本語を、カーソルのある場所に入力するアプリです。音声の認識はすべて PC の中で行い、インターネットには接続しません。

Powered by Moonshine AI

## ダウンロード

| OS | ファイル |
| --- | --- |
| Windows 10 / 11 | `privdicta-0.2.1-windows-setup.exe` |
| macOS（Apple Silicon の Mac のみ） | `privdicta-0.2.1-macos-arm64.dmg` |
| Linux（x86_64） | `privdicta-0.2.1-linux-x86_64.AppImage` |

インストールの手順と使い方は `privdicta-user-guide-ja.md` にあります。

## 0.2.1 で変わったこと

- マイクを使えないときに、理由と「マイクの設定を開く」ボタンのある画面を出すようにしました。これまでは、通知が一瞬出るだけでした。Windows では、「設定 > プライバシーとセキュリティ > マイク」で「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」がオフになっていると、マイクを使えません。PrivDicta は OS の設定を変えないので、この画面から設定を開いてオンにしてください
- リリースに添付する使い方のファイル名を `privdicta-user-guide-ja.md` にしました。0.2.0 では `default.md` という名前になっていました

## 注意

- **Windows：** 電子署名がないため、初回の実行時に「Windows によって PC が保護されました」と表示されます。「詳細情報」から「実行」を押してください。スマート アプリ コントロールがオンの PC では、実行が止められることがあります。
- **macOS：** Apple の署名と公証を受けていません。初回は右クリックして「開く」を選んでください。Intel の Mac には対応していません。
